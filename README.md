# ZoneWars

ZoneWars is a 3D open-world action RPG concept inspired by Invincible. The game supports two origin paths:
- Raised as a Viltrumite conqueror
- Raised on Earth as a heroic protector

## Key Features
- Multi-planet 3D exploration: Earth, Viltrum, alien worlds, canon-inspired locations.
- Fast aerial and ground combat with combo attacks and cinematic finishers.
- Destructible environments, dynamic world events, and branching morality.
- Progression through power levels, skill trees, reputation, and customization.
- Branching storylines with hero and conqueror endings.
